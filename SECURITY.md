# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| < 0.6   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `vajra-lm`, please send an email to security@vajra-lm.org. Please do NOT open public GitHub issues for security vulnerabilities.
