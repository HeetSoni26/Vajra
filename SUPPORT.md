# Support Guidelines

Welcome to the Vajra support page!

## Where to Get Help

### 1. Documentation
Before asking for support, please review our comprehensive technical documentation in the [`docs/`](docs/) directory:
- [Architecture Guide](docs/architecture.md)
- [Training Guide](docs/training.md)
- [Release Pipeline](docs/release_pipeline.md)
- [FAQ](docs/faq.md)

### 2. GitHub Issues
- **Bug Reports**: If you encounter an unexpected crash or bug, open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: To suggest new architecture modules or tooling features, open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).

### 3. GitHub Discussions
Use GitHub Discussions for Q&A, general architecture discussions, hardware performance tuning, and community pretraining ideas.
