# Vajra Production Dataset Manifests

This manifest details the recommended open-source datasets for training Vajra models.

## 1. FineWeb (HuggingFaceFW/fineweb)
- **Description**: Massive, high-quality filtered web dataset.
- **Estimated Size**: 15TB (full), 10B/100B token subsets available.
- **Vajra Usage**: Primary pretraining corpus.
- **Download**:
  ```python
  from datasets import load_dataset

  ds = load_dataset("HuggingFaceFW/fineweb", name="sample-10BT", split="train")
  ```
- **License**: ODC-By 1.0

## 2. SlimPajama (cerebras/SlimPajama-627B)
- **Description**: Thoroughly deduplicated version of RedPajama.
- **Estimated Size**: ~800GB (627B tokens).
- **Vajra Usage**: Core pretraining mixture.
- **License**: Apache 2.0

## 3. Cosmopedia (HuggingFaceTB/cosmopedia)
- **Description**: Synthetic textbook dataset generated by Mixtral.
- **Estimated Size**: ~30B tokens.
- **Vajra Usage**: Enhances reasoning and educational quality.
- **License**: Apache 2.0

## 4. OpenWebMath (keiranking/OpenWebMath)
- **Description**: High-quality mathematical web text.
- **Estimated Size**: ~14B tokens.
- **Vajra Usage**: Boosts mathematical reasoning capabilities.
- **License**: ODC-By 1.0

## 5. The Stack v2 (bigcode/the-stack-v2)
- **Description**: Permissively licensed source code.
- **Estimated Size**: >3TB.
- **Vajra Usage**: Code generation and logical structuring.
- **License**: Custom/Permissive

## Preparation Workflow
1. Download subset via HuggingFace `datasets`.
2. Convert to `.jsonl` chunks.
3. Run `python -m scripts.prepare_dataset` to tokenize and pack into `.bin` using `tokenizer/v1.0`.
