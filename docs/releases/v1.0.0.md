# Vajra v1.0.0 — Production Release

We are excited to announce the official **v1.0.0** public release of **Vajra**, an open-source, production-grade foundation language model framework engineered for auditability, reproducibility, and end-to-end transparency.

---

## Project Overview

Vajra provides a unified, production-tested software stack for training, evaluating, and packaging decoder-only Transformer models from scratch. Developed with an engineering-first philosophy, Vajra ensures every dataset shard, pretraining run, evaluation metric, and release artifact is byte-for-byte reproducible and cryptographically signed with SHA-256 manifest verification.

---

## Major Highlights

- **Vajra-57M Foundation Model**: Pretrained base model (`90,317,312` parameters) validated on FineWeb-Edu corpora.
- **8/8 Verification Engine**: Automated release verifier (`release.verify_package`) enforcing strict compliance across configuration schemas, tokenizer assets, weight integrity, metadata consistency, and checksums.
- **Cross-Platform Deterministic Builds**: Native LF line ending normalization (`newline="\n"`) and static Git commit timestamp integration ensuring identical build signatures across Linux, macOS, and Windows.
- **Agent & Stateful Memory System**: Integrated multi-agent task orchestrator, persistent conversation memory, RAG context builders, and factual knowledge graph storage (`vajra_agent/`).
- **Comprehensive Test Suite**: **248 unit and integration tests** passing with 100% stability.

---

## Architecture Summary

Vajra implements a decoder-only LLaMA-style causal Transformer with modern optimizations:
- **Rotary Position Embeddings (RoPE)** ($\theta = 10000.0$)
- **Root Mean Square Normalization (RMSNorm)** ($\epsilon = 1.0 \times 10^{-6}$)
- **SwiGLU Activation Function** ($d_{ff} = \frac{8}{3} d_{model}$)
- **Grouped-Query Attention (GQA)** ($N_q = 8, N_{kv} = 4$)
- **Tied Word Embeddings** (`tie_word_embeddings = true`)

## Quick Start

### Loading Model & Generating Text
```python
from inference.generation import Generator
from model.architecture import FoundationLM, ModelConfig

config = ModelConfig(
    vocab_size=65536,
    hidden_size=512,
    intermediate_size=1376,
    num_layers=8,
    num_attention_heads=8,
    num_key_value_heads=4,
    max_position_embeddings=2048,
)
model = FoundationLM(config)
generator = Generator(model=model, tokenizer_path="tokenizer/v1.0")

output = generator.generate("The future of open-source AI is", max_new_tokens=50)
print(output)
```

### Verifying Release Package
```bash
python -m release.verify_package --package-dir release/vajra-57m
```

## Known Limitations

- **Base Foundation State**: `Vajra-57M` is an unaligned pretraining base model without RLHF or instruction tuning safety filters.
- **Scale**: `Vajra-57M` is designed as a micro-scale foundation reference model (`90M` total parameters); larger variants are in active development.
